# 暗涌行动 · 搜打撤

单文件浏览器搜打撤游戏。

## 怎么玩

下载 [index.html](./index.html)，用浏览器直接打开即可游玩。

也可以在线游玩：<https://xingyingyuzhui.github.io/anyong-extraction/>

## 地图

共四张地图，在大厅「开始游戏 → 行动部署」里选择：

- **暗涌港区**：原版地图
- **航天基地**：发射台、总装厂房、指挥控制中心、燃料储罐区，地下指挥所 B1
- **巴克什**：沙漠古城，大巴扎、清真寺、王宫，地下蓄水宫
- **大坝**：水库坝体、水电站、管理局，河道分隔东西两岸

每张新地图都有配电开关、后期撤离点、付费撤离点、巡逻车、探照灯、空投和钥匙卡房间。存档在各版本之间通用。
